## Full Description

**LocalDrop** lets you send and receive files, photos, videos, documents, and entire folders directly between your Android devices and companion desktop computers over your local Wi-Fi or wired network—with no cloud servers, accounts, or internet uploads required.

### Key Features

- **Direct Local Transfers**  
  Discover nearby peers automatically on the same network via mDNS and stream files directly device-to-device.

- **Cross-Platform Desktop Companion**  
  Built to interoperate seamlessly with companion Tauri desktop applications on Windows, macOS, and Linux.

- **Folder Hierarchy Preservation**  
  Send multi-file batches or entire directory trees while preserving nested folder structures.

- **QR Code Pairing & Encrypted Trust**  
  Pair devices quickly by scanning a temporary QR code. Trusted peer credentials are encrypted locally using Android Keystore.

- **Explicit Consent & Safety Checks**  
  Incoming transfers require explicit confirmation by default, validate filenames and paths against traversal, and check SHA-256 checksums before saving.

- **Transfer History & File Browser**  
  Review completed transfers, filter received files by category, customize your save folder via Android's system folder picker, or manage storage directly in the app.

- **Built-In Diagnostics & Home Widgets**  
  Check Wi-Fi interfaces, test peer latency, view categorized error details, and monitor status from Home Screen Glance widgets.

### Privacy First

LocalDrop does not upload your files, device names, or usage analytics to any remote server. All discovery, pairing, transfer history, and error logs stay strictly on your device and local network.
